# 一、LLM 大语言模型
## 1. 在 Transformer 中，为什么需要位置编码？
### 什么是位置编码？

简单来说，**位置编码（Positional Encoding）就是给输入的词贴上一张“序号/位置的标签”**。

在自然语言中，词语的顺序对句意至关 direction 关重要（比如“张三打李四”和“李四打张三”，用词完全一样，但含义截然相反）。
由于 Transformer 架构的核心模块——自注意力机制（Self-Attention）是并行计算所有词的，它在处理文本时就像把一句话里的词全部扔进一个“词袋”里，只计算词与词之间的相关性，**默认完全没有方向和先后顺序概念**。

位置编码的作用，就是将词的“位置/顺序信息”转化为向量，与词本身的语义向量融合在一起，让模型在计算语义的同时也能识别出每个词在句子中的物理位置。

---

### 为什么在 Transformer 中它是必需的？

1. **自注意力机制是“排列不变”的（Permutation Invariant）：**
在没有位置编码的情况下，无论打乱输入序列中词的顺序，Self-Attention 算出来的上下文语义表达都是完全一致的。没有位置编码，Transformer 就无法理解语法结构和语序逻辑。
2. **替换传统循环结构（RNN）的必然要求：**
传统的 RNN/LSTM 是按时间步“逐字读取”文本的，天然带有时间先后顺序；而 Transformer 为了实现大规模并行训练抛弃了循环结构，因此必须通过显式注入位置编码来补充丢失的位置信息。

---

### 位置编码的常见实现方式

#### 1. 绝对位置编码（Absolute Positional Encoding）

直接为序列中的每个绝对位置（第 1 个词、第 2 个词……）分配唯一的 位置向量。

* **正弦/余弦周期函数编码（Sinusoidal Encoding，原论文 Transformer 使用）：**
* **原理**：利用不同频率的 `sin` 和 `cos` 函数公式直接计算出每个位置的固定向量值。
* **优点**：无需参数训练，计算快；且通过三角函数的和差公式，模型具有推导出相对位置关系的数学潜能。


* **可学习的位置编码（Learned Absolute Position Embedding，如 BERT、GPT-2）：**
* **原理**：将位置向量作为模型的可训练参数（类似于词表 Embeddings），在模型训练过程中自动学习每个位置的最佳表示。
* **缺点**：泛化能力受限，无法很好地处理超出训练时预设最大长度的序列。



#### 2. 相对位置编码（Relative Positional Encoding）

不再关注某个词的绝对序号，而是**关注词与词之间的距离（相对偏移量 $i - j$）**。

* **典型代表（如 RoPE 旋转位置编码 / ALiBi / T5 位置偏置）：**
* **RoPE（Rotary Position Embedding，当前主流大模型如 LLaMA / Qwen 标配）**：通过复数旋转矩阵将位置信息隐式注入到 Query 和 Key 向量的内积计算中，既保留了相对位置的几何性质，又极大地提升了模型对外推（处理更长上下文）的能力。
* **ALiBi（Attention with Linear Biases）**：在注意力得分矩阵上直接加上一个与距离成正比的负偏置惩罚，距离越远注意力关注度越低，无需额外训练位置向量，外推能力强。
